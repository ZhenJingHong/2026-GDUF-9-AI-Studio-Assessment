# 接口文档（v0.1 草案）

> 前后端联调依据。字段有变动必须先改这份文档并在群里通知，避免各写各的。

## 通用约定

- Base URL：`http://localhost:8080`
- 编码：UTF-8，请求与响应均为 `application/json`
- 时间格式：`yyyy-MM-dd HH:mm:ss`（如 `2026-11-11 12:30:00`）
- 日期格式：`yyyy-MM-dd`（如 `2026-11-11`）
- 金额：数字，单位元，最多两位小数
- 分类枚举（固定九个，不允许自由发挥）：

  `餐饮` `交通` `购物` `娱乐` `居住` `医疗` `教育` `其他`

### 路径前缀分工

| 前缀 | 负责人 | 内容 |
| --- | --- | --- |
| `/api/ai`   | 钟嘉和 | AI 解析、OCR、查账意图 |
| `/api/bill` | 邱卓成 | 账单增删查 |
| `/api/stat` | 陈宇亮 | 统计与趋势 |

### 统一响应结构

成功：

```json
{
  "code": 0,
  "message": "ok",
  "data": { }
}
```

失败：

```json
{
  "code": 50001,
  "message": "AI 服务调用失败，请稍后重试",
  "data": null
}
```

| code | 含义 |
| --- | --- |
| 0 | 成功 |
| 40001 | 参数缺失或格式错误 |
| 40002 | 分类不在枚举内 |
| 40401 | 资源不存在 |
| 50001 | AI 服务调用失败 |
| 50002 | AI 返回内容无法解析成 JSON |

## 一、AI 模块（负责人：钟嘉和）

### 1. 健康检查

`GET /api/ai/ping`

响应：

```json
{ "code": 0, "message": "ok", "data": "pong" }
```

### 2. 一句话记账解析

`POST /api/ai/parse-bill`

请求：

```json
{ "text": "昨天打车32块，和同事AA" }
```

响应 `data`（BillDraft，未入库）：

```json
{
  "amount": 32.0,
  "category": "交通",
  "merchant": null,
  "occurredAt": "2026-11-11 12:30:00",
  "note": "打车",
  "confidence": 0.95
}
```

字段说明：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| amount | number \| null | 金额，识别不出为 null |
| category | string \| null | 必须是九个分类之一，识别不出为 null |
| merchant | string \| null | 商户名 |
| occurredAt | string \| null | 消费时间，未提及则由后端补当天 |
| note | string | 原文摘要 |
| confidence | number | 0~1，模型自评置信度 |

**约定**：`amount` 或 `category` 为 null 时，前端必须让用户补填，不允许直接入库。

### 3. 小票 / 截图识别

`POST /api/ai/ocr-receipt`

请求：`multipart/form-data`，字段名 `file`，支持 `jpg / png / webp`，单张 ≤ 10MB。

响应：同 `parse-bill` 的 `data` 结构（BillDraft）。

**约定**：识别结果一律回填到表单里让用户确认后再调 `/api/bill`，不允许绕过确认直接入库。

### 4. 自然语言查账意图解析

`POST /api/ai/query`

请求：

```json
{ "text": "上个月吃饭花了多少" }
```

响应 `data`（QuerySpec）：

```json
{
  "action": "stat",
  "start": "2026-10-01",
  "end": "2026-10-31",
  "category": "餐饮",
  "aggregate": "sum",
  "keyword": null
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| action | string | `stat` 统计 / `list` 明细 / `unknown` 无法理解 |
| start | string | 起始日期 `yyyy-MM-dd` |
| end | string | 结束日期，含当天 |
| category | string \| null | 分类，null 表示全部 |
| aggregate | string \| null | `sum` / `count` / `max` / `avg` |
| keyword | string \| null | 商户或备注关键词 |

**约定**：前端拿到 `action=stat` 就调 `/api/stat` 下的接口，`action=list` 就调 `/api/bill`；`action=unknown` 时前端回复「没听懂，能换个说法吗」，不要把原话直接丢给模型自由回答。

## 二、账单模块（负责人：邱卓成）

### 5. 新增账单

`POST /api/bill`

请求（BillDraft + 可选补充）：

```json
{
  "amount": 32.0,
  "category": "交通",
  "merchant": "滴滴",
  "occurredAt": "2026-11-11 12:30:00",
  "note": "打车"
}
```

响应 `data`（Bill，已入库）：

```json
{
  "id": 1,
  "amount": 32.0,
  "category": "交通",
  "merchant": "滴滴",
  "occurredAt": "2026-11-11 12:30:00",
  "note": "打车",
  "createdAt": "2026-11-12 10:00:00"
}
```

### 6. 查询账单列表

`GET /api/bill?month=2026-11&category=餐饮&keyword=滴滴`

参数均可选：

| 参数 | 说明 |
| --- | --- |
| month | `yyyy-MM`，不传查全部 |
| category | 分类名，不传查全部 |
| keyword | 商户/备注模糊匹配 |

响应 `data`：Bill 数组。

### 7. 删除账单

`DELETE /api/bill/{id}`

响应：`{"code": 0, "message": "ok", "data": null}`；不存在返回 `40401`。

## 三、统计模块（负责人：陈宇亮）

### 8. 按分类统计

`GET /api/stat/category?month=2026-11`

响应 `data`：

```json
{
  "month": "2026-11",
  "total": 607.5,
  "items": [
    { "category": "餐饮", "total": 320.5, "count": 12 },
    { "category": "交通", "total": 88.0, "count": 4 },
    { "category": "购物", "total": 199.0, "count": 3 }
  ]
}
```

**约定**：`items` 只返回有数据的分类，按 `total` 降序；`total` 为所有分类之和，方便前端算占比。

### 9. 月度趋势

`GET /api/stat/trend?from=2026-09&to=2026-11`

响应 `data`：

```json
{
  "months": ["2026-09", "2026-10", "2026-11"],
  "totals": [820.0, 756.5, 607.5]
}
```

### 10. 任意日期范围统计

`GET /api/stat/range?start=2026-11-01&end=2026-11-12&category=餐饮&aggregate=sum`

本接口已在 `StatsController` 实现，供前端处理 AI 返回的 `action=stat`。

| 参数 | 说明 |
| --- | --- |
| start / end | 必填，`yyyy-MM-dd`，结束日期含当天，start 不可晚于 end |
| category | 可选，固定分类之一 |
| keyword | 可选，商户或备注关键词 |
| aggregate | 可选，默认 sum；支持 sum / count / max / avg |

响应 `data` 示例：

```json
{
  "start": "2026-11-01",
  "end": "2026-11-12",
  "category": "餐饮",
  "keyword": null,
  "aggregate": "sum",
  "value": 320.5
}
```

无匹配账单时 sum/count 为 0，max/avg 为 null。参数错误返回 HTTP 400，仍使用统一响应结构，业务 code 为 40001 或分类错误的 40002。

## 四、统计模块补充：按日期范围统计

### 10. 按日期范围统计

`GET /api/stat/range?start=2026-11-01&end=2026-11-30&category=餐饮&aggregate=sum`

参数：

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| start | 是 | 起始日期 `yyyy-MM-dd` |
| end | 是 | 结束日期 `yyyy-MM-dd`，含当天 |
| category | 否 | 分类，不传表示全部；必须在九个枚举内，否则返回 40002 |
| keyword | 否 | 商户或备注关键词 |
| aggregate | 否 | `sum`（默认）、`count`、`max`、`avg` |

响应 `data`：

```json
{
  "start": "2026-11-01",
  "end": "2026-11-30",
  "category": "餐饮",
  "keyword": null,
  "aggregate": "sum",
  "value": 320.5
}
