# 从 11 月 5 日查到 18 日

这个接口解决一个具体问题。假如你问「11 月 5 日到 18 日，吃饭花了多少钱？」，AI 先找出日期、分类和「求和」这件事。然后 Java 用这些条件查账单，返回数据库算出来的数字。你可以直接用浏览器试第二步。

## 1. 在 IDEA 启动后端

在 IDEA 里打开包含 `pom.xml` 的目录 `D:\rgzn\2026-GDUF-9-AI-Studio-Assessment`。在底部打开 **Terminal**，用 PowerShell 运行这几行。

```powershell
$env:JAVA_HOME = 'C:\Program Files\Eclipse Adoptium\jdk-25.0.5.8-hotspot'
$env:AI_API_KEY = 'test-placeholder'
.\mvnw.cmd spring-boot:run '-Dspring-boot.run.arguments=--server.address=127.0.0.1 --spring.h2.console.enabled=true --spring.datasource.url=jdbc:h2:mem:stats-range-demo'
```

看到 `Started BackendApplication` 后保留终端。这里的 `test-placeholder` 是本地测试用的占位值，日期统计直接读数据库。

## 2. 往 H2 填四笔账单

打开 [H2 数据库控制台](http://localhost:8080/h2-console)。`JDBC URL` 填 `jdbc:h2:mem:stats-range-demo`，`User Name` 填 `sa`，密码留空，点击 **Connect**。复制下面的 SQL，点一次 **Run**。

```sql
INSERT INTO bill (category, amount, occurred_at, merchant, note) VALUES
    ('餐饮', 12.50, TIMESTAMP '2026-11-05 00:00:00', '小林咖啡', '美式'),
    ('餐饮', 32.50, TIMESTAMP '2026-11-18 23:59:59', '便利店', '买咖啡'),
    ('交通',  8.00, TIMESTAMP '2026-11-10 12:00:00', '地铁', NULL),
    ('餐饮', 60.00, TIMESTAMP '2026-11-19 00:00:00', '餐馆', '晚饭');
```

## 3. 用浏览器看结果

[打开 5 日到 18 日的餐饮统计](http://localhost:8080/api/stat/range?start=2026-11-05&end=2026-11-18&category=%E9%A4%90%E9%A5%AE&aggregate=sum)。`code` 为 `0` 表示成功，`data.value` 就是答案 `45`。这两笔餐饮分别发生在第一天的零点和最后一天的晚上，所以都算进去。地铁那笔属于交通，60 元餐饮那笔发生在 19 日。

保持日期和分类，试着修改网址最后一个参数。

| 参数 | `data.value` | 含义 |
| --- | ---: | --- |
| `aggregate=sum` | `45` | 12.50 加 32.50 |
| `aggregate=count` | `2` | 两笔餐饮 |
| `aggregate=max` | `32.50` | 最贵的一笔 |
| `aggregate=avg` | `22.50` | 45 除以 2 |

在原网址末尾加 `&keyword=小林`，会查到 `12.50`。去掉 `category` 和 `keyword`，同一日期范围的总金额就是 `53`。如果把结束日期改到起始日期之前，`code` 会变成 `40001` 并提示日期顺序有误。

## 4. 从 Java 方法读起

1. 在 [StatsController.java](../src/main/java/com/example/backend/stat/StatsController.java) 找到 `range()`。`@RequestParam` 把网址里的文字交给方法。Java 用 `LocalDate` 表示日期，顺便检查像 2 月 30 日这样的输入。
2. 在 [StatsRepository.java](../src/main/java/com/example/backend/stat/StatsRepository.java) 找到 `summarizeRange()`。`WHERE` 选出符合条件的账单，`SUM` 加金额，`COUNT` 数笔数，`MAX` 找最大的金额。日期筛选到 19 日零点之前，所以 18 日一整天都算进去。
3. 在 [StatsService.java](../src/main/java/com/example/backend/stat/StatsService.java) 找到 `range()`。`switch` 根据你传的 `aggregate` 选结果。平均金额用总额除以笔数。`return new RangeStat(...)` 创建一个装有答案的对象，Spring Boot 把它转成浏览器里的 JSON。

练完后在终端按 `Ctrl+C` 关闭后端。H2 存在内存里，下次启动时可以重新插入这四笔账单。
