# 时间与原账单更正

- 新账单 timePrecision=DATE 表示只知道日期，EXACT 表示有明确时刻。日期型记录为兼容既有字符串日期查询仍以00:00:00存储，但前端不把它当作真实消费时刻展示。旧数据午夜没有精度信息时显示“时间未指定”。手动填写时间按EXACT保存。
- “现在/刚刚/此刻”使用上海时区的消息发送时刻。只说日期或未提供具体时刻时按日期记录，不猜测午饭几点。多轮补充金额时保留原消费时间。
- 前端在有原入账记录、没有待补充草稿时拦截“改/更正/记错”等表述，不交给新增意图解析。只在本会话已记录的账单中查找目标，支持昨天/前天/今天/日期或#编号；多笔时要求明确编号。
- 更正金额显示修改前后数值，确认后通过 PUT /api/bill/{id}/amount 更新原账单；不新增、不删除记录。重复相同PUT不会产生额外账单。金额需大于0且最多两位小数。
- 历史上已经误新增的重复账单不会自动删除。需要用户在账单中核对并删除多记项。

验证：前端构建成功，Spring Boot使用18084独立数据库启动。浏览器固定识别响应（非本次真实模型请求）驱动30元、60元、更正40元及查询流程，实际API/数据库验证昨天合计40、原账单数量不增加，DATE/EXACT保存与现在时刻正确；同一天有多笔时无自动修改。真实DeepSeek多轮调用在本轮修改之前已验证，此次时间/更正主要为确定性前端处理。

此更改位于临时整合分支。后端新增字段和接口，旧进程必须重启才能生效。已运行的原main不替换，远程main未修改。
