# 日期范围统计技术交接

负责人为陈宇亮。`GET /api/stat/range` 供 AI 查账的 `action=stat` 使用，也可独立调用。金额和笔数来自账单数据库。环境为 JDK 25、Spring Boot 4.1.2 和项目现有的 H2 联调表。

## 请求与响应

| 查询参数 | 规则 |
| --- | --- |
| `start`, `end` | 均必填，严格使用 `yyyy-MM-dd`，有效范围为 `0001-01-01` 至 `9999-12-31`，允许同一天，`start` 不得晚于 `end` |
| `category` | 可选，使用团队接口文档约定的中文分类名。省略、留空或只传空白时查全部分类 |
| `keyword` | 可选，去掉首尾空白后，对商户名或备注做忽略大小写的子串匹配。`%`、`_` 和 `!` 按原字符匹配。没有有效文字时忽略此条件 |
| `aggregate` | `sum`、`count`、`max`、`avg`，忽略大小写。省略或留空时默认 `sum` |

`category` 和 `keyword` 同时传入时，账单须满足两个条件。查询按消费时间 `occurred_at` 归属日期，从 `start` 当天零点开始，到 `end` 次日零点之前。

成功时返回 HTTP 200 和统一响应 `ApiResponse`。`data` 回显起止日期、规范化后的筛选条件和统计方式，结果在 `value`。金额是 JSON 数字，单位为元，笔数是整数。空结果的处理如下。

| `aggregate` | `value` 含义 | 无匹配账单 |
| --- | --- | --- |
| `sum` | 总金额 | `0` |
| `count` | 账单笔数 | `0` |
| `max` | 最高单笔金额 | `null` |
| `avg` | 平均每笔金额，四舍五入到分 | `null` |

日期缺失、日期无效、起止颠倒或 `aggregate` 不支持时返回 HTTP 400、`code: 40001`。分类不在枚举内时返回 HTTP 400、`code: 40002`。两种错误的 `data` 均为 `null`。

## 接入 AI 查账

例如用户问「11 月 5 日到 18 日，餐饮一共花了多少钱？」。`POST /api/ai/query` 可先返回以下 `data`。

```json
{"action":"stat","start":"2026-11-05","end":"2026-11-18","category":"餐饮","aggregate":"sum","keyword":null}
```

前端判断 `action` 为 `stat`，检查起止日期齐全，再把 `start`、`end`、`category`、`aggregate` 和 `keyword` 作为查询参数发给 `/api/stat/range`。构建 URL 时对中文和特殊字符编码，省略值为 `null` 的可选参数。日期缺失时先请用户补充。账单明细由 `action=list` 的对应模块处理。

```text
GET /api/stat/range?start=2026-11-05&end=2026-11-18&category=%E9%A4%90%E9%A5%AE&aggregate=sum
```

使用[新手指南](日期范围统计-新手指南.md)的示例账单时，后端返回以下内容。前端拿 `data.value` 就能显示「这段时间餐饮花了 45 元」。

```json
{"code":0,"message":"ok","data":{"start":"2026-11-05","end":"2026-11-18","category":"餐饮","keyword":null,"aggregate":"sum","value":45.00}}
```

## 代码和验证

- `StatsController.range` 负责解析参数、校验分类和返回 `ApiResponse`。
- `StatsService.range` 接收 `LocalDate` 和 `RangeAggregate`。一次数据库查询返回总额、笔数和最高单笔，平均值用 `BigDecimal` 将总额除以笔数，按 `HALF_UP` 保留两位小数。
- `StatsRepository.summarizeRange` 在 H2 的 `bill` 表上用绑定参数筛选。正式账单模块合入后，应核对 `occurred_at`、`category`、`amount`、`merchant`、`note` 的映射并复跑联调。

在 JDK 25 下执行以下命令。占位值用于启动现有的 AI 配置，统计测试用 H2 执行 SQL。

```powershell
$env:AI_API_KEY = 'test-placeholder'
.\mvnw.cmd -B -ntp verify
```
