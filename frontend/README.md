# 小账 Pocket AI · Vue 前端

基于仓库 `docs/接口文档.md` v0.1 草案制作。技术栈：Vue 3 Composition API、Vite、ECharts、Lucide 图标。采用响应式布局，支持手机和桌面。

## 启动

要求 Node.js 20.19+ 或 22.12+。在本目录打开终端：

```bash
npm install
npm run dev
```

访问终端显示的地址，通常为 http://127.0.0.1:5173 。生产构建：`npm run build`，预览：`npm run preview`。

默认进入本地演示模式，示例账单、手工添加与删除记录保存在浏览器 localStorage；AI 记账使用简单规则预填，界面明确标注，并不是模型识别。切换月份不会修改示例记录的日期。预算也保存在浏览器中，不会上传。

## 与后端联调

1. 本目录为仓库根目录下的 `frontend`，与后端 `pom.xml` 并排。
2. 按后端 README 启动 Spring Boot，默认端口 8080。
3. 运行本前端，在「账本设置」将数据来源改为「连接 Spring Boot 后端」。
4. 开发时 `/api` 由 Vite 转发到 `http://localhost:8080`，无需额外配置 CORS。后端地址可通过启动 Vite 前设置 `API_TARGET` 修改。
5. 生产部署需要反向代理 `/api` 到后端；或者构建前配置 `VITE_API_BASE` 为后端完整 API 地址，并在后端配置允许前端来源的 CORS。不要向前端写入 AI API Key。

## 已实现

- 总览：真实支出合计、日均、预算剩余、每日消费趋势、分类分布、最近账单。
- 账单：月份/分类/关键词筛选、手动新增、二次确认删除、导出筛选结果 CSV。
- AI：自然语言解析、小票上传识别、可编辑草稿确认、自然语言查询接口请求；统计意图调用 `/api/stat/range`，支持求和、计数、平均、最大值；明细意图查询账单后按日期范围过滤。这些真实接口尚待运行联调。
- 设置：演示/后端模式切换、本地预算。
- 请求超时、业务错误、空状态、加载提示、重复提交禁用与图片类型/大小检查。

## 接口映射

| 功能 | 接口 |
| --- | --- |
| 列表、新增、删除 | GET/POST `/api/bill`、DELETE `/api/bill/{id}` |
| 分类与月度趋势 | GET `/api/stat/category`、`/api/stat/trend` |
| 任意日期范围统计 | GET `/api/stat/range` |
| 自然语言草稿 | POST `/api/ai/parse-bill` |
| 小票识别 | POST `/api/ai/ocr-receipt`，FormData 字段 `file` |
| 查询意图 | POST `/api/ai/query`，再查询账单 |

遵循 `{code,message,data}` 响应封装。识别结果必须核对后手动保存，缺少金额或分类时不可提交。时间保存为 `yyyy-MM-dd HH:mm:ss`。文档写「九个分类」但实际只列八项，因此严格使用已列举的八项，不自行增加分类。没有添加后端不存在的用户登录、收入、账单编辑或预算接口。

统计接口失败时显示提示，并使用当前真实账单计算分类及每日趋势。月度趋势可用时在「消费分析」中展示。真实后端请求失败不会悄悄切换演示数据。
